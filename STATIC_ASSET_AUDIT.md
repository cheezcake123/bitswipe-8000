# Static Asset Provenance Audit

Audit date: 2026-07-26

This is an inventory/provenance audit, not legal advice or a legal conclusion.

## Scope

The repository was scanned for image, icon, font, and other static media files. The audit records file path, byte size, SHA-256, repository history, and source/generation evidence.

## Historical snapshot assets

The eight media paths below originally entered this downstream repository in snapshot commit `1540ab4dbda206535a477623c9f39310d2ba2007` (`chore: capture current deployed BitSwipe 8000 state`). That snapshot did not establish who created those original bytes, where they came from, or what license applied to them.

Those historical versions therefore remain `UNKNOWN` as provenance records. Replacing the current files does not erase the old bytes from Git history.

## Current replacement assets

The current branch replaces all eight previously-UNKNOWN media files with a new geometric decision-compass/lens asset family generated specifically for this downstream project.

Generation source: `scripts/generate_brand_assets.py`

The generator:

- uses only the Python standard library
- makes no network calls
- consumes no external images, icon packs, fonts, logos, or source artwork
- constructs PNG, ICO, SVG, and Open Graph media from geometric primitives and fixed project palette values
- supports `--check` to verify that checked-in assets exactly match deterministic generated bytes
- supports `--write` to regenerate the checked-in assets

## Design/source record

The replacement mark is intentionally brand-neutral: a rounded dark field, an outlined circular lens/compass, a diagonal decision needle, a center hub, and a small watch-state dot. The Open Graph image uses the same mark plus abstract modular decision rails/bars. It contains no Bitcoin logo, third-party brand mark, copied UI screenshot, external font, or imported artwork.

This establishes reproducible repository-local provenance for the **current** eight media files. It does not make a legal conclusion about copyrightability or ownership of simple geometric shapes.

## Historical-asset caveat

The former UNKNOWN files remain present in earlier public Git commits. This audit records that fact rather than rewriting repository history. No destructive history rewrite is performed as part of this work.

## Upstream project provenance

The project README references `https://github.com/likegyu/bitcoin-trading-manager`. A full upstream Git-history scan established that its first README already described the project as `MIT`, but no historical `LICENSE`, `COPYING`, or `NOTICE` file and no complete copyright-and-permission text were recovered. See `PROVENANCE_AUDIT.md`.

## Remaining release/compliance work

1. Obtain or independently verify the original upstream project's exact copyright/license notice.
2. Continue reducing upstream implementation dependence through behavior-preserving, independently designed rewrites where appropriate.
3. Determine whether downloadable/deployment artifacts redistribute third-party packages; prepare required license texts/notices for anything actually redistributed.
4. Keep dependency licenses, upstream-code provenance, historical media provenance, and downstream branding decisions as separate records.

## Tooling

- `scripts/static_asset_inventory.py` performs read-only asset inventory.
- `scripts/generate_brand_assets.py` deterministically generates and verifies the current replacement media set.
